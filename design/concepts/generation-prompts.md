# Промпты концепций интерфейса

Способ: встроенный image_gen, три отдельных изображения.

Все сведения о технике, заказах, сотрудниках и датах демонстрационные. Изображения предназначены для обсуждения визуального направления; элементы процессов подлежат дальнейшему уточнению.

## 01 · Синий и графит

Use case: ui-mockup. Generate a polished high-fidelity UI design presentation for a Russian desktop web application named "РемонтЦентр" used by maintenance specialists repairing underground mining machinery. This is an actual operational workbench, not a promotional website or analytics dashboard. Create ONE tall ultra-high-resolution image, ideally 2160 x 3840, consisting of THREE complete desktop screen mockups stacked vertically with narrow labeled dividers. Each screen has a wide desktop aspect ratio approximately 1.75:1, occupies almost the full image width, and is fully visible, with no overlap, perspective, laptop frames, photography or decorative empty areas. All UI text in excellent legible Russian Cyrillic. Render typography equivalent to 16–18 CSS px body on a 1440px-wide desktop, 14px minimum secondary, 28px page titles, line height 1.4, generous enough row height 48–52px. Professional consistent sans-serif like Segoe UI/Inter. Sharp crisp text and fine clean icons. Compact, calm information density: strong alignment, thin separators, 8px corner radii, restrained shadows, modest margins 20–24px. The actual application fills each screen. No oversized statistic tiles, charts, giant headings, ornamental backgrounds, excessive nested cards or tiny text. 95% useful content with comfortable readability, not crammed.
Board header small: "РемонтЦентр" plus specified palette title and three color swatches with exact hex labels. Tiny board footer "Концепция интерфейса · Демонстрационные данные".
Keep EXACT SAME STRUCTURE AND DEMO CONTENT across all three color concept images so they can be compared fairly.

Shared application shell: 210px sidebar on left with small geometric tool icon next to "РемонтЦентр"; menu labels "Рабочее место", "Оборудование", "План ТО", "Ремонтные заказы", "Дефекты", bottom "Справочники", "Настройки". Each menu item a simple line icon AND text. Highlight current menu only. A slim top bar contains search "Поиск техники, заказов, дефектов", site "Участок Северный", profile initials "АС". Avoid redundant navigation.
